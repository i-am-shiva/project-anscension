PROJECT ASCENSION — FITNESS RPG V1

Features:
- Log exercise, set number, reps, weight, unit, and optional notes.
- Save dated workouts and inspect history.
- Compare two weeks by sessions, total reps, exercise-specific best logged weight, and estimated volume.
- XP, levels, ranks, daily missions, streak display, badges, and animations.
- Local browser storage, JSON export/import backup, responsive installable PWA setup.

TRY ON LAPTOP:
1. Extract ZIP.
2. For a quick preview, open index.html in a browser.
3. For offline/PWA features, run `python -m http.server 8000` in this folder and open http://localhost:8000. Service workers need localhost or HTTPS.

INSTALL ON ANDROID:
To install as an app, host these files at an HTTPS address (GitHub Pages or another static host), open the HTTPS site in Chrome on Android, then use browser menu > Install app / Add to Home screen. Merely copying the ZIP to your phone does not install a PWA.
Progress is stored separately on each device. Use Export and Import to transfer records. A conventional APK can be made later using Android tooling.

DATA:
Data is stored locally in your browser, not in cloud. Export backups regularly; clearing browser data can erase records. No account or cloud sync. The weekly report compares what you logged; changes alone do not prove better form or strength.
